# DEV BYTE

Frontend foundation built with React, TypeScript, Vite, and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

Run `npm run build` for the TypeScript check and production build.

## Project foundation

- Tailwind theme tokens and bundled Inter Variable font are in `src/index.css`.
- Reusable UI components belong in `src/components/ui`.
- Routes and the responsive navigation shell are defined in `src/App.tsx`.
- The Axios instance for future API calls is in `src/lib/api/client.ts`.
- No backend or API behavior is implemented in this frontend foundation.

Feature routes currently show temporary placeholders. See
`docs/PHASE_1_FOUNDATION_REPORT.md` for the current scope and remaining work.
